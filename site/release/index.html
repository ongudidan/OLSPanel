  • Feature Enhancement

    • Automatic, human-friendly file size formatting (B / KB / MB / GB).
    • Upload preview now shows converted size next to each file name.

    • Clearer understanding of file sizes during upload.
    • No need to manually convert KB to MB or GB.
    • Improved experience for both small and large uploads.
